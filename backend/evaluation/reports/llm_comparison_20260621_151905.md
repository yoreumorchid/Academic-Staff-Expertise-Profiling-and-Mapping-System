## Interpretation Guide

1. **Hard F1** measures exact string match after canonicalisation
   (lowercase, punctuation stripped, singularisation). This is a
   strict metric — 'Deep Learning' and 'deep-learning' match, but
   'Deep Learning' and 'Neural Networks' do not.

2. **Soft F1** measures semantic equivalence via SciBERT cosine
   similarity ≥ 0.7. This catches cases where
   the LLM produces a synonymous but differently-worded tag.
   Soft F1 is the metric that matters for *user-facing quality*.

3. **Success Rate** below 100% indicates the LLM returned
   unparseable output at least once. This is the most common
   failure mode with non-OpenAI providers (especially DeepSeek,
   which wraps responses in JSON arrays). Our production code
   already handles this with the array-unwrap fallback.

4. **Cost** is estimated from public pricing and token-count
   approximations. Actual costs vary with prompt length.
